# my-skills

个人 skill 收藏库。

- **`paper-review/`** — 论文深度阅读与结构化 review 管线（自用）
- **`doc-driven-dev/`** — 文档驱动的科研项目开发工作流（自用）
- **[`THIRD-PARTY-SKILLS.md`](THIRD-PARTY-SKILLS.md)** — 收藏的他人 skill，只记录 GitHub 地址

## 用法

自己的 skill 通常以 `<name>/SKILL.md` 结构存放，复制到 agent 的 skills 目录（如 `~/.workbuddy/skills/`、`~/.claude/skills/`）即可加载。第三方 skill 不复制进仓库，按需去各自仓库安装，避免仓库膨胀与上游失去同步。

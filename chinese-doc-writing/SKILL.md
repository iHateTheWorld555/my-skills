# 中文文档写作

三层模型，由小到大：

```
句子写作 —— 句子内部：选词、句式、标点、混排
单篇文档 —— 一篇之内：意图、标题、段落、列表、表格
文档体系 —— 多篇之间：类型划分、目录结构、导航、交叉链接
```

**适用范围**：通用文档。技术文档（README、API 参考、教程、操作指南）按全套规则执行；叙述性文档（博客、评论、观点文）只执行标了「通用」的规则，结构层规则降为弱推荐。

**与 yanru-blog-voice 的关系**：用户要求按其个人博客风格写文章时，yanru-blog-voice 优先，本 skill 只在其画像未覆盖处（排版、标点、混排）作补充。本 skill 管的是文档，不是文章。

## 写作流程

**第一步：受众四问**（写任何文档之前必须先答）

1. 这篇文档给谁看？
2. 读者为什么来读，他要完成什么？
3. 读者读之前已经知道什么？
4. 读完之后应该知道什么、会做什么？

四问答完，文档类型和大纲就能直接推出来。答案答不全时先问用户，不要自己编读者。

**第二步：判定文档类型**（类型决定骨架，详见 references/corpus.md）

| 类型 | 回答的问题 | 骨架 |
|---|---|---|
| 教程 tutorial | 你能教我吗？ | 一节课：环境准备 → 分步操作 → 验证结果 |
| 操作指南 how-to | 我该怎么做 X？ | 前提条件 → 编号步骤 → 结果验证 |
| 参考 reference | 这个参数/接口是什么？ | 按条目组织，供检索，不要求通读 |
| 阐释 explanation | 为什么这样设计？ | 论述：背景 → 问题 → 方案 → 取舍 |

**一篇文档只服务一个意图。** 混合意图就拆成多篇，互相链接。

**第三步：出大纲确认**。大纲每条只描述一个概念或一个任务；开头写 scope 声明（本文覆盖什么、不覆盖什么、前置知识是什么）。大纲先给用户确认再动笔。

**第四步：逐层写作**，对表三份参考：

- 句子层规则 → references/sentence.md
- 单篇层规则 → references/document.md
- AI 腔清除 → references/ai-slop.md（AI 生成的初稿必查；这一层治的病与 sentence.md 不同源）
- 文档腔清除 → references/ai-slop-doc.md（写文档必查：查证凭证、合规声明、加粗划重点、可再生统计、重复信息）

**第五步：自检**。

```bash
python3 scripts/check.py <file.md>
```

脚本覆盖可机械化的句子层规则；其余规则（结构、意图、豁免判断）人工对表检查。

## 规则分档

规则按强制度分三档（借自 RFC2119）：

- **MUST（必须）**：有唯一正确答案，脚本可查或一眼可判。错就是错，不讨论。
- **SHOULD（应该）**：有明确依据，但存在正当例外。例外要在文中能说清理由。
- **MAY（可选）**：风格偏好。skill 已选定默认值，用户明确要求时才改。

各规则在参考文件中标注所属档位。token 紧张时按 MUST > SHOULD > MAY 的顺序取舍。

## 冲突裁决表

材料之间有三处实打实的冲突，skill 已裁决如下（MUST）：

| 项 | 裁决 | 依据 |
|---|---|---|
| 括号 | 括号内纯英文/数字用半角 `( )`，前后空一格；括号内含中文用全角（），前后不空格 | zh-style-guide（更精细） |
| 引号 | 简体中文用大陆弯引号，先双后单：“…” 内 ‘…’；不用直角引号「」 | clreq 大陆横排规范 |
| 数值范围 | 前后两个数值都带单位：132 kg～234 kg，15%～30% | 阮一峰（保守口径） |

## 句子层与 AI 层的关系

两类病不同源，都要查：

- **sentence.md** 治的是人会犯的病（英式中文、翻译腔、认知负担），素材是 1987–2020 年的写作规范。AI 同样会犯——训练语料里全是这种句子。
- **ai-slop.md** 治的是 agent 特有的病（纠正式揭示、数字化枚举、破折号澄清、完成宣告、责任移交），素材是本 agent 自己 63 万字历史输出的实测统计。外网流传的 AI slop 词表（delve、赋能、抓手）在本 agent 语料中密度约为零，不是本 agent 的病。

改稿顺序：先用 ai-slop.md 第一节判断句式骨架（病在结构不在词），写/改文档再过一遍 ai-slop-doc.md 的五条判据，最后用 sentence.md 修句子。顺序反了就是在给模板腔抛光。ai-slop-doc.md 的一句总判据：这句话删掉后，文档作为事实记录是否仍然完整成立？是，就删。

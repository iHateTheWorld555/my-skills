# Review Scoring Rubric

评分的唯一依据。Review agent 用本文件逐条评估文本，三个维度独立打分（0-100），取加权或按任务要求的维度报告。

评分立场：像严格的会议 reviewer 读 camera-ready 一样读文本。80 分线的含义是"没有阻断性缺陷，剩余扣分点属于润色级别"。

## 维度一：Structure（结构与逻辑）100 分

| 检查项 | 分值 |
|---|---|
| S1 论点层级：每个段落有唯一 message，且能映射到章节论点（reverse outline 能画出来） | 20 |
| S2 首句点题：段首句陈述该段要做什么，读者读完首句能预测段落内容 | 15 |
| S3 逻辑链完整：任务→挑战→方案→优势→证据的链条无跳步；前后因果方向正确 | 20 |
| S4 术语一致：同一概念全文同名；新术语先定义后使用 | 15 |
| S5 声明-证据对齐：每个 major claim 有实验证据支撑；没有过强的表述 | 20 |
| S6 冗余：没有重复表达同一信息的段落；没有与论点无关的句子 | 10 |

structure 扣分示例：reverse outline 时发现某段无法映射到任何论点（S1 -10）；"our method" 与 "the proposed approach" 混用（S4 -5）。

## 维度二：Flow（语句流畅）100 分

| 检查项 | 分值 |
|---|---|
| F1 主语位：句首名词承载该句话题；读者在句首看到旧信息/已知信息 | 20 |
| F2 强调位：句尾放该句最重要的新信息；不以次要细节收尾 | 15 |
| F3 旧-新契约：句与句之间旧信息引出新信息，话题线连续，无突兀跳跃 | 20 |
| F4 动词承载动作：没有成串的 nominalization（把动作藏进名词）；主语是角色、谓语是动作 | 15 |
| F5 简洁：无空词（kind of, actually, in order to→to）、无迂回表达、无重复堆叠 | 15 |
| F6 过渡与衔接：句间关系（因果/转折/递进）有明确标记或靠旧新衔接自然成立 | 15 |

flow 扣分示例：连续三句各自开头引入全新话题，话题线断裂（F3 -10）；"the utilization of X for the purpose of Y" 类迂回（F5 -5）。

## 维度三：Grammar（语法正确性）100 分

| 检查项 | 分值 |
|---|---|
| G1 冠词：a/an/the 使用正确；泛指复数与不可数名词不误加 the；方法名/数据集名冠词惯例正确 | 25 |
| G2 时态：章节时态分配正确；描述他人工作/自己方法/实验操作的时态区分正确 | 20 |
| G3 一致与单复数：主谓一致；不可数名词误用复数、拉丁复数（criteria/phenomena）正确 | 15 |
| G4 句法：无逗号粘连、run-on、fragment；无悬垂修饰语；平行结构完整 | 20 |
| G5 介词与搭配：无高频介词错配与中式搭配 | 10 |
| G6 细节：大小写、数字单位、缩写定义、连字符、et al. 格式正确 | 10 |

grammar 扣分示例：'a novel loss function' 写成 'the novel loss function'（G1 -5）；"Based on the above analysis, the experiments are conducted..." 悬垂修饰（G4 -5）。

## 任务维度映射

| 任务 | 评分维度 |
|---|---|
| 结构修改 | structure（若改动波及句子，加评 flow） |
| 流畅修改 | flow |
| 语法检查 | grammar |
| 全文/投稿前审查 | structure + flow + grammar 三维都评，总分 = 三者平均 |

## 输出格式要求

Review agent 必须输出：

```
总分：NN/100（多维度时为加权/平均分，注明计算方式）
各维度：structure NN / flow NN / grammar NN（未评的维度标 n/a）
逐条扣分点：
  [维度+编号] 原文片段（≤20词） → 扣 N 分 → 理由（一句话）
一句话总评。
```

禁止输出：泛泛的"写得不错"；没有原文片段的扣分；没有分值的评价。

## 科学含义保护条款（评分 agent 同样要查）

flow 与 grammar 修改最容易把科学表述改错。逐句对照修改前后文本，出现以下任一情况，直接判不通过并指出：

1. 主张强度变化：suggest → demonstrate，或反之
2. 限定范围丢失：'on COCO' 被删；'in our experiments' 被删
3. 因果方向反转；数字、单位、模型名被改
4. hedging 词被删除或新增不当（may → 不加任何限定）

此类问题在输出中单独列出，标 `SCIENCE-MEANING-CHANGE`，不计入分数扣减但必须修复。
